# clipr user guide

clipr records your games in the background and saves the last moments when you press a hotkey. It's open
source, needs no account and never hooks into games.

- **[Getting started](getting-started.md):** install, the first-run setup, saving clips, the gallery, full
  recordings, using it from your phone, updates and uninstalling.
- **[Every setting explained](settings.md):** each option on the Settings page, tab by tab, with its default.
- **[Discord](discord.md):** post clips to a channel with a webhook, step by step.
- **[Troubleshooting](troubleshooting.md):** logs, crash reports, known limits and common questions.

The **Help** link at the top of the clipr page opens this guide.

For developers: the local web API is described in [docs/api.md](../api.md), and building clipr in
[CONTRIBUTING.md](../../CONTRIBUTING.md).
